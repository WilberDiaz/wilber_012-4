# 🛒 ShopMaster – Tienda Web con Carrito, Pago y Ticket PDF  
### Proyecto educativo | HTML | CSS | JavaScript | Bootstrap | API | jsPDF

---

## 📌 Descripción del proyecto

**ShopMaster** es una tienda virtual moderna y responsiva creada con tecnologías web esenciales.  
Consume una API real de productos, permite ver detalles, agregar artículos al carrito, realizar un pago simulado y generar un **ticket térmico en PDF**, similar a los recibos de un negocio real.

Este proyecto está orientado a:

- Estudiantes de desarrollo web  
- Emprendedores que desean crear tiendas online rápidas  
- Personas que buscan aprender HTML, CSS y JavaScript de forma práctica  
- Portafolios profesionales  

---

## 🎯 Características principales

### 🛍️ 1. Consumo de API real  
Productos obtenidos desde:  
https://fakestoreapi.com/products

### 💳 2. Carrito de compras  
- Agregar productos  
- Modificar cantidad  
- Eliminar artículos  
- Guardar carrito con LocalStorage  
- Cálculo automático del total  

### 🔍 3. Modal de detalles  
- Imagen grande  
- Descripción  
- Precio  
- Selector de cantidad  

### 💳 4. Pasarela de pago simulada  
Validación de:
- Nombre del cliente  
- Número de tarjeta  
- Fecha de vencimiento  
- CVV  

### 🧾 5. Ticket PDF tipo térmico  
Generado con **jsPDF** usando:
- Formato pequeño (58 mm)  
- Texto monoespaciado  
- Productos comprados  
- Cantidades  
- Totales  
- Fecha y hora  

### 📱 6. Diseño moderno y responsivo  
Construido con **Bootstrap 5** y **Font Awesome**.

---

## 🧩 Tecnologías utilizadas

| Tecnología        | Uso                                        |
|------------------|---------------------------------------------|
| **HTML5**        | Estructura de la tienda                     |
| **CSS3**         | Estilos y diseño visual                     |
| **Bootstrap 5**  | Componentes y diseño responsivo             |
| **JavaScript ES6** | Lógica del carrito, modales, pago y PDF   |
| **Font Awesome** | Íconos del proyecto                         |
| **Fetch API**    | Consumo de la API externa                   |
| **LocalStorage** | Persistencia del carrito                    |
| **jsPDF**        | Generación del ticket térmico en PDF        |
